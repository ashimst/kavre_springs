# Kavre Springs — map of a community water-source inventory

Interactive map of the 5,689 springs and ponds in ICIMOD's inventory for seven palikas of Kavrepalanchok, Nepal,
with the main results of the accompanying spatial audit. Built with **React 19**, **Vite** and **Leaflet**.

Every number on the site comes from `src/data.json`, which is generated by the analysis pipeline:

```bash
python -m src.export_frontend_data      # run from the repository root after reproduce_all.py
```

Do not edit `data.json` or type numbers into the components by hand; re-export instead.

---

## What the site shows

1. **Map**: district and palika boundaries (MoFAGA via geoBoundaries), all sources coloured by recorded condition,
   and an optional OpenStreetMap ward layer shaded by how many of each recorded ward's sources fall inside its polygon.
2. **Descriptive charts**: share of sources recorded as dried by elevation, road distance, recorded land use and
   aspect; recalled causes; reported drying year (treated as Bikram Sambat). These are raw shares, not adjusted.
3. **Wards and catchments**: ICC of recorded drying for wards and DEM catchments on the observed (ANOVA) and latent
   (logit) scales, ward results against random reference partitions, and direct ward–catchment differences.
4. **Palikas**: share recorded as dried in each surveyed palika.
5. **Survey audit**: questionnaire skip logic, leak-free prediction, and recorded location against boundaries.

The site describes recorded data. It does not show causes of drying or true vulnerability.

## Deploying to Cloudflare Pages

### Option A: Via GitHub Integration (Continuous Deployment)
1. In the **Cloudflare Dashboard**, navigate to **Workers & Pages** $\rightarrow$ **Create Application** $\rightarrow$ **Pages** $\rightarrow$ **Connect to Git**.
2. Select your repository `kavre_springs`.
3. In the build settings:
   - **Framework preset**: `Vite`
   - **Root directory**: `frontend`
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
4. Click **Save and Deploy**. Cloudflare Pages will build the site and provide a free global edge URL (e.g., `https://kavre-springs.pages.dev`).

### Option B: Direct CLI Deployment (Wrangler)
```bash
cd frontend
npm run build
npx wrangler pages deploy dist --project-name kavre-springs
```
